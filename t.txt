What is the difference between class-based and function-based views in Django REST Framework?

Answer:
I mentioned that function-based views (FBVs) are simple and explicit but not ideal for larger APIs. Class-based views (CBVs) and Generic views in DRF provide reusable and extendable logic — for example, ListCreateAPIView or RetrieveUpdateDestroyAPIView. I prefer CBVs as they reduce code duplication and handle CRUD operations efficiently.

Explain how JWT Authentication works in Django REST Framework.

Answer:
I faced this question before — I have used that JWT (JSON Web Token) is used for stateless authentication. When a user logs in, a token with a signature is generated and returned. The client stores it (usually in localStorage) and sends it in headers (Authorization: Bearer <token>) for each request. On the server, DRF verifies the token before granting access.

Answer:
I have answered this multiple times — I said GET is used to fetch data, POST to create new resources, PUT to update existing data completely, and DELETE to remove a resource. In DRF, these are mapped automatically in APIView or ViewSet classes.

Answer:
